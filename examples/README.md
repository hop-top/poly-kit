# examples

runnable integration samples.

## Contents

- [spaced/](spaced/README.md): satellite mission control demo.
- [probe/](probe/README.md): minimal cross-language probe.
- [served/](served/README.md): conformance fixture for zero-wiring served commands.
- [notebook/](notebook/README.md): interactive notebook server.
- [relay/](relay/README.md): bus-to-bus relay demo.
- [multiprotocol/](multiprotocol/README.md): REST+WS+RPC showcase.
- [datasette/](datasette/README.md): browse a kit instance's SQLite state with Datasette.
- [cmdsurface/](cmdsurface/README.md): one cobra tree projected onto every invocation surface.
- [cmdsurface-faas/](cmdsurface-faas/README.md): the same bridge behind the FaaS adapters.
- [notebook-py/](notebook-py/README.md): Python notebook CLI on the `kit-engine` SDK.
- [notebook-ts/](notebook-ts/README.md): TypeScript notebook CLI on `@hop-top/kit-engine`.
- [notebook-sidecar/](notebook-sidecar/README.md): Go notebook CLI using `kit serve` as a sidecar.
- [registry/](registry/README.md): mDNS service discovery registry for kit apps.
- [spaced-noncompliant/](spaced-noncompliant/README.md): deliberately non-compliant fixture binary; not a starting point.
