# core

Operational primitives every kit tool shares: config, identity, policy
guardrails, upgrades, agent-CLI awareness.

## Contents

| Path | What it is | Start here when |
|------|------------|-----------------|
| [`avatar/`](avatar/README.md) | avatar URL facade (dicebear built in) | you need a picture for a seed |
| [`breaker/`](breaker/README.md) | runtime circuit breakers, byte and op caps | you must bound an operation's blast radius |
| [`compliance/`](compliance/README.md) | 12-factor AI CLI conformance checks | you verify a tool against the spec |
| [`config/`](config/README.md) | layered YAML loader, PKL, hot reload | you read or write tool configuration |
| [`consent/`](consent/README.md) | telemetry consent state machine | you need to know if the user opted in |
| [`id/`](id/README.md) | TypeID entity identifiers | you mint or parse an entity ID |
| [`identity/`](identity/README.md) | local-first cryptographic identity | you sign, verify or trust a peer |
| [`netpolicy/`](netpolicy/README.md) | `--offline` marker and transport guard | your code reaches the network |
| [`projects/`](projects/README.md) | reader/writer for the rux project registry | you resolve a registered project |
| [`redact/`](redact/README.md) | secret and PII egress filter | text leaves the process |
| [`scope/`](scope/README.md) | allow/deny filesystem path policy | your tool touches paths |
| [`stage/`](stage/README.md) | scope operating-mode primitive | you declare active, freeze, sunset |
| [`upgrade/`](upgrade/README.md) | self-update and versioned migrations | your binary or its data must move forward |
| [`util/`](util/README.md) | shared helpers | you need a small cross-cutting function |
| [`uxp/`](uxp/README.md) | agent CLI detection and invocation | your tool talks to Claude, Codex, Gemini and peers |
| [`xdg/`](xdg/README.md) | per-tool XDG directories and files | you need a config, data, cache or state path |

## Conventions

- Vendored rule corpora live in `scope/rules` and `redact/rules` and are regenerated by `tools/`, never edited.
