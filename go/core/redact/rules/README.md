# rules

## What it answers

Where the Presidio PII corpus embedded by `go/core/redact` comes from,
which upstream tag it is pinned to, what was dropped, and how it is
refreshed. Matching and replacement is `go/core/redact`; the secret
corpus is `go/core/scope/rules`.

## Use it when

- you want the compiled PII rules: `redact.LoadPresidio(redact.DefaultPresidioPath())`, or `redact.Default()` which loads both corpora
- you need a different corpus in production: set `KIT_REDACT_PII_RULES_PATH` to a TOML file with the same layout
- you bump the corpus: `make refresh-pii-rules`, then vet the diff per the "Maintaining PII rules" section of `redact/README.md`

## Quick start

```go
rs, err := redact.LoadPresidio(redact.DefaultPresidioPath())
if err != nil {
    fmt.Println("err:", err)
    return
}
fmt.Println(len(rs) > 0)
// Output: true
```

## Contract

- Vendored: `presidio-pii.toml`, `LICENSE` from `github.com/microsoft/presidio` at tag `2.2.362`, MIT. `SOURCES.md` in this directory is the provenance record.
- Generated by `tools/vendor-presidio` from its `curated.go`; patterns were hand-translated to portable RE2 because Presidio ships Python `Pattern` objects. Same tag and unchanged `curated.go` yield byte-identical output.
- Refresh target: `make refresh-pii-rules`, or `make refresh-rules` for both corpora.
- v1 coverage: email, phone (US and E.164), US SSN, US ITIN, credit card (regex only, no Luhn), IBAN, IPv4, IPv6, US passport, US driver license. Dropped upstream: `CRYPTO`, `MEDICAL_LICENSE`, `UK_NHS`, `URL`.
- Rule-id collisions with the gitleaks corpus resolve in favour of gitleaks; the PII rule gets the `-pii` suffix at load time.
- No Go package lives here: the TOML is embedded from `go/core/redact/loader.go`. The TS and Python `redact` ports load the same file verbatim.

## Neighbours

- `go/core/redact`: `LoadPresidio`, `Default`, replacement strategies.
- `go/core/scope/rules`: the gitleaks corpus.
- `tools/vendor-presidio`: the generator and its curated list.
